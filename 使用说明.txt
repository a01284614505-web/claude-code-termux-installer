================================
Claude Code Termux 安装包
使用说明
================================

📥 你收到了 Claude Code 的安装包！
按照下面的步骤操作即可。

================================
第一步：下载并解压
================================

1. 保存 zip 文件到手机

2. 打开 Termux 应用
   （如果没有安装，先从 F-Droid 下载安装）

3. 在 Termux 中输入以下命令：

   cd ~/storage/downloads
   
   unzip claude-code-termux-installer*.zip
   
   cd claude-code-termux-installer

提示：如果提示没有 unzip，先运行：pkg install unzip

================================
第二步：运行安装
================================

在 Termux 中输入：

   bash install.sh

然后等待 5-10 分钟，会自动安装所有依赖。

安装过程会显示进度，不要关闭 Termux！

================================
第三步：配置 API
================================

安装完成后，需要配置群里的 API。

1. 创建配置文件：

   nano ~/.config/claude-code/credentials.env

2. 输入以下内容（记得改成群里公布的真实密钥）：

   ANTHROPIC_AUTH_TOKEN='群里的密钥'
   ANTHROPIC_BASE_URL='https://sui-xiang.com'

3. 保存并退出：
   - 按 Ctrl+X
   - 按 Y
   - 按 Enter

4. 设置权限：

   chmod 600 ~/.config/claude-code/credentials.env

================================
第四步：启动使用
================================

1. 重新加载环境变量：

   source ~/.bashrc

2. 启动 Claude Code：

   claude

3. 第一次启动会让你选主题，推荐选 2 (Dark mode)

4. 然后就可以开始对话了！

================================
常用命令
================================

启动 Claude Code：
   claude

查看版本：
   claude --version

在对话中：
   /model          查看/切换模型
   /help           查看所有命令
   /exit           退出

================================
遇到问题？
================================

📚 查看详细文档：

   cat QUICKSTART.md    # 快速上手
   cat FAQ.md           # 常见问题

🔧 常见问题快速修复：

问题1: 提示 "command not found: claude"
解决: source ~/.bashrc

问题2: 启动卡住不动
解决: 检查网络，检查 API 配置是否正确

问题3: 提示 "Invalid API key"
解决: 重新检查 credentials.env 中的密钥

问题4: 安装失败
解决: pkg update && pkg upgrade 然后重新运行 install.sh

📱 在手机上查看文档：
